First public release.

**Install:** download `AutoBrightnessTile-v1.3.apk` below, install it, open the app, allow **Modify system settings**, then tap **Quick panel tile → Add**.

- One-tap adaptive brightness tile for the quick panel (made for Samsung One UI, works on Android 8.0+)
- No Shizuku, ADB or root
- Tile stays in sync with the system setting; long-press opens Display settings
- Half-sun icon drawn to One UI's quick-panel proportions
- About 40 KB, no internet permission
